# Frontend Pivot to Streamlit

This directory originally contained React/TypeScript scaffolding but we have
pivoted to Streamlit for rapid, high-impact UI development.

## Files
- `streamlit_app.py` - Main interactive loan evaluation dashboard
- `components/` - Removed empty scaffolding (now integrated into Streamlit)
- `dashboard/` - Removed empty scaffolding (now integrated into Streamlit)

## Usage
```bash
streamlit run frontend/streamlit_app.py
```

The Streamlit app provides:
- Interactive loan application forms
- Real-time API integration with FastAPI backend
- Professional multi-tab results display
- Compliance checking and explainable AI visualization
